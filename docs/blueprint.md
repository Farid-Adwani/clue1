# **App Name**: Tunisian Treasure Hunt

## Core Features:

- Dodging Button: A button labeled 'Download Dictionary' that moves randomly when the user tries to click it. This happens until it's clicked 15 times.
- Background Images: Display background images related to Tunisian civilization, such as mosaics or historical landmarks.
- Dictionary Access: Once the button is clicked 15 times, the user can download the dictionary.

## Style Guidelines:

- Primary color: Gold (#D4AF37), inspired by the opulence of Tunisian artifacts.
- Background color: Soft beige (#F5F5DC), mimicking the color of ancient Tunisian architecture.
- Accent color: Deep red (#A70021), referencing the rich textiles and dyes used in Tunisian crafts.
- Font pairing: 'Playfair' (serif) for headlines, conveying elegance, and 'PT Sans' (sans-serif) for body text.
- The 'Download Dictionary' button will appear in the center of the screen.
- Smooth transition animations when the background images change or the button moves.
- Use of cultural symbols for the button and other icons, linking them to Tunisian traditions and history.
